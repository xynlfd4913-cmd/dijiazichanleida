# 全口径成本引擎

## 1. 目标

成本引擎回答的不是“起拍价是多少”，而是“取得资产并达到可用或可售状态，可能占用多少现金、最终消耗多少成本、还有哪些费用没有核验”。所有计算必须为可重复、可测试的纯函数。

## 2. 基本公式

```text
all_in_cost_min = estimated_bid
                + sum(known_fee_min)
                + sum(estimated_fee_min)

all_in_cost_max = estimated_bid
                + sum(known_fee_max)
                + sum(estimated_fee_max)
                + explicit_risk_reserve

safe_margin = conservative_resale_value - all_in_cost_max

safe_roi = safe_margin / all_in_cost_max

max_recommended_bid = conservative_resale_value
                    - non_bid_cost_max
                    - target_profit
                    - risk_reserve
```

`unknown` 费用没有金额，不能直接进入求和，也绝不按 0 处理。数值区间必须标记为 provisional：只要存在未知费用，机会最高只能为 B；未知项超过允许阈值时直接为 `Skip`。缺少有效市场参照时，变现价、价差、ROI 与最大建议出价保持 `null`，不能继续生成推荐等级。

## 3. 保证金与现金门槛

保证金通常在成交后抵扣价款或在未成交时退还，因此默认不作为额外成本重复相加。但它会暂时占用现金：

```text
minimum_cash_required = max(
    deposit,
    immediate_payment_requirement + immediate_non_bid_costs
)
```

并单独展示 `estimated_capital_lock_days`。如果用户资产本金不足以支付保证金，即使预计最终成本较低，也必须判定本金不适配。

## 4. 费用状态

### known

来源公告、合同、收费标准或有效账单给出明确金额或区间。证据应能定位。

### estimated

来自可解释的报价、距离公式、资产模板或人工估价。必须保留估算方法、日期和区间，不能只存一个神秘数字。

### unknown

公告出现风险提示但无法确定金额，或重要信息缺失。`min_amount` 与 `max_amount` 均为 `null`。产品显示“未知待核验”，而不是将成本区间伪装成完整结果。

## 5. 费用分类

通用费用包括：买方佣金、平台服务费、辅助拍卖服务费、税费、过户与登记、欠费、拆卸、吊装、叉车、搬运、运输、安装、维修、配件、检测、仓储、腾退、清场、停车、拖车、销售平台扣费、资金占用与风险准备金。

类别模板在 `config/cost_rules/default.json`：

- 机械设备：拆装、吊装、运输、安装、电气改造、缺件、检测、维修、仓储；
- 车辆：拖车、停车、维修、保养、年检、保险、过户、钥匙、证件和牌照限制；
- 房产：税费、登记、物业、水电气、装修、占用、租赁、腾退和交付；
- 库存：数量、破损、过期、缺件、仓储、包装、物流与销售扣点；
- 知识产权：年费、维持费、登记、有效期、许可状态与商业化成本。

模板创建“需要核验的费用槽位”，并不自动给出金额。

## 6. 文本触发词

`config/keywords/hidden_costs.json` 保存首版词库，例如“由买受人承担”“现状交付”“费用不详”“自行拆除”“自行腾退”“无法过户”“欠费”“以实际为准”。

识别到触发词后的动作是：

1. 生成或关联一个 CostItem；
2. 默认状态为 `unknown`；
3. 保存最小证据文本和来源定位；
4. 等待规则、人工询价或凭证把状态更新为 `estimated` / `known`。

文本模型可以帮助定位和分类证据，但不能自行填写金额。

## 7. 确定性与取整

- 所有输入先转为 `Decimal`；
- 货币统一按 0.01 元量化；
- ROI、阈值和其他比例内部至少保留四位小数，比较前不得按金额精度取整；
- 除法分母为 0 或关键值为空时返回不可计算，而非抛出误导性结果；
- 相同输入必须得到相同输出，算法不得读取当前时间、随机数或大模型响应。

## 8. 示例

某设备预计成交 6,500 元，拆装 200–500 元，运输 300 元，维修 1,000–2,000 元，平台费 100 元，风险准备金 500 元，保守快速变现价 10,500 元：

```text
all_in_cost_min = 6500 + 200 + 300 + 1000 + 100 + 500 = 8600
all_in_cost_max = 6500 + 500 + 300 + 2000 + 100 + 500 = 9900
safe_margin = 10500 - 9900 = 600
safe_roi = 600 / 9900 ≈ 6.06%
```

即便评估价显示 12,000 元，结论仍应是“表面折价较大，但真实安全空间较小”。若另有未知吊装费用，页面必须额外展示待核验风险。

## 9. 审计要求

每次计算至少保留：公式版本、输入资产快照指纹、费用项目及证据、保守变现价参照、用户约束、计算时间与输出。人工修正必须新增审计记录，不静默覆盖来源事实。
